# PY Course — Viktor Nikoriak

Ласкаво просимо 👋

Цей курс — Python українською, від основ до просунутих тем. Матеріали складаються з двох частин:

- **Ноутбуки занять** (у папках `module_N/lessons/`) — те, з чим ти працюєш на занятті: короткий контекст, умова завдання, код.
- **Ця книга** — повний виклад теорії, довідники, інструкції по роботі з Git/GitHub.
