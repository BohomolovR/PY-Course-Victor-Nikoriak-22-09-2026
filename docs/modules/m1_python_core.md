## Концепція модуля

М1 будується не як послідовність ізольованих тем Python, а як поступове формування **computational thinking** через одну наскрізну модель мислення:

```text
задача → інформація → дані → перетворення → організація логіки → збереження та взаємодія → система
```

Це не один наскрізний проєкт на весь модуль — це одна модель, яку демонструють на різних задачах на різних етапах, аж до фінального CLI-проєкту на позиції 17.

Git/GitHub — окремий **паралельний трек**, що йде поруч із Python з першого заняття (Pull Request — цільовий спосіб здачі домашніх робіт), а не тема, яку відкладають до кінця модуля.
