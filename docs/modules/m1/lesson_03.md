## CONCEPT

### Змінна — це ярлик, не коробка

Найважливіша ментальна модель цього уроку: змінна в Python **не** зберігає значення в собі, як коробка. Вона діє як посилання ("ярлик"), що вказує на об'єкт у пам'яті.

```python
a = 5
```

Тут відбувається два кроки: спочатку створюється об'єкт цілого числа `5`, потім ім'я `a` починає посилатися на цей об'єкт.

Звідси випливає, що відбувається під час копіювання:

```python
a = 5
b = a
a = 10
print(b)  # 5 — b досі вказує на старий об'єкт 5, а не на a
```

`b = a` не копіює об'єкт — вона створює нове посилання на той самий об'єкт у пам'яті. Коли `a` пізніше починає вказувати на інший об'єкт (`10`), це ніяк не змінює те, на що вказує `b`.

### Іменування змінних

Допустимі символи — літери, цифри, символ підкреслення (`_`); ім'я не може починатися з цифри; пробіли заборонені; Python чутливий до регістру (`spam != Spam`). За PEP 8 — нижній регістр зі словами через підкреслення: `user_age`, `total_sum`.

### Примітивні типи даних

У Python усе — об'єкт, але кілька типів називають примітивними, бо вони представляють прості, неподільні значення:

| Тип | Приклад | Призначення |
|---|---|---|
| `int` | `42`, `-5` | цілі числа |
| `float` | `3.14`, `-1.2` | числа з плаваючою крапкою |
| `str` | `"text"`, `'hello'` | текст |
| `bool` | `True`, `False` | логічні значення |
| `None` | `None` | відсутність значення |

### Рядки незмінні (immutable)

Після створення рядка його внутрішній вміст змінити неможливо:

```python
s = "abc"
s[0] = "x"
# TypeError: 'str' object does not support item assignment
```

Будь-яка операція, що виглядає як «зміна» рядка, насправді створює новий об'єкт:

```python
s = "hello"
s = s + " world"  # старий рядок не змінився — у пам'яті з'явився новий
```

Незмінність — не обмеження заради обмеження. Вона дає три речі одразу: рядки можна безпечно використовувати як ключі `dict` і елементи `set` (їхній хеш стабільний, поки об'єкт живий), Python може повторно використовувати однакові рядки в пам'яті, а поведінка коду стає передбачуванішою — ніхто не змінить рядок «у вас під рукою» через інше посилання на нього.

### Динамічна, але строга типізація

Типу змінної не потрібно оголошувати наперед — одна й та сама змінна може послідовно посилатися на різні типи:

```python
x = 10
x = "hello"
```

Але кожен об'єкт у пам'яті завжди має чітко визначений тип, і Python суворо контролює, які операції для нього дозволені. Це не суперечність, а свідомий баланс: **свобода** (самі імена змінних не мають типу й можуть вказувати на будь-що) + **правила** (кожен об'єкт завжди знає свій тип, і Python це перевіряє).

### Чому Python вимагає явного перетворення типів

```python
"spam" + 5
# TypeError: can only concatenate str (not "int") to str
```

JavaScript чи PHP в цій ситуації мовчки повернули б `"spam5"`. Python дотримується принципу **«явне краще за неявне»** (Zen of Python) і не намагається вгадати, що ви мали на увазі. Це дає дві переваги: якщо у вас є `"42" + 5`, Python не вирішує сам, хотіли ви число `47` чи рядок `"425"` — він одразу зупиняється помилкою, замість того щоб мовчки обрати варіант і, можливо, зламати логіку далі в програмі. Явне перетворення (`int("42") + 5` або `str(42) + "5"`) змушує програміста сформулювати намір одразу в коді:

```python
value = '42'
print(int(value) + 5)   # 47 — явно як число
print(value + "5")      # '425' — явно як рядок
```

### Duck typing — гнучкість без втрати контролю

Щоб компенсувати строгість типів, Python використовує **утину типізацію**: «якщо воно виглядає як качка, плаває як качка і крякає як качка — це качка». Python не перевіряє, до якого класу належить об'єкт — його цікавить лише поведінка:

```python
for item in obj:
    print(item)
```

Цьому циклу байдуже, чи `obj` — це `list`, `tuple`, `str`, генератор чи власний клас. Головне, щоб він підтримував ітерацію. Так само `+` працює для будь-якого об'єкта, що реалізує магічний метод `__add__()` — не обов'язково для чисел.

### Оператори

| Оператор | Опис | Приклад |
|---|---|---|
| `+ - * **` | арифметика | `2 ** 10 == 1024` |
| `/` | ділення, завжди `float` | `10 / 4 == 2.5` |
| `//` | цілочисельне ділення (округлення вниз) | `10 // 4 == 2` |
| `%` | остача від ділення | `10 % 4 == 2` |
| `+` (рядки) | конкатенація | `"Hi" + " there"` |
| `*` (рядки) | повторення | `"Hi" * 3` |

**Передбачте, що виведе Python**, перш ніж перевіряти: `1 + 2 * 3`, потім спробуйте скласти вираз із `1`, `2`, `3`, `+` та `*`, що дорівнює `9` — пріоритет операцій вирішує, а не порядок написання.

## MODIFY

### Робота з символами: `ord()` і `chr()`

`ord()` перетворює символ у його числовий код, `chr()` — навпаки:

```python
print(ord('A'))   # 65
print(chr(66))    # 'B'
print(chr(ord('a') + 3))  # 'd' — зсув літери
```

Це фундамент для роботи з текстом на рівні символів — кодування, і, зокрема, шифрування. **Повна вправа на шифр Цезаря — не тут**, вона переїхала на практикум П1 (урок 8), разом з іншими базовими алгоритмічними задачами. Тут — лише невеликий приклад роботи із символами, щоб зрозуміти механіку `ord`/`chr`, без готового рішення шифру.
