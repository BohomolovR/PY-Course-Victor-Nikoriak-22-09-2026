# Урок 9. Декоратори

Тип: Урок. Організація рішення — cross-cutting concerns (логування, авторизація тощо) без зміни коду функції.

Джерело (аудит): докс L09 (closures, `nonlocal`, wrapper, 10 тестів) + `lesson_14_decorators_architecture.ipynb` (logger/authorization/middleware-chain, `functools.wraps`, `lru_cache`, міні-проєкт «Система обробки платежів»). Перед основним матеріалом потрібен короткий вступний блок «функції — це теж об'єкти» (`function → значення → можна передати/повернути → function→function → decorator`) — prerequisite-місток, не заміна повного розгляду first-class functions, який іде пізніше, в М2 (позиція 18).
