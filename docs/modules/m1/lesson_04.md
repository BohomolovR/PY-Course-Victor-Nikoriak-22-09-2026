# Урок 4. Булевий тип, if, while (+ input, імпорти)

Організація рішення: розгалуження та повторення.

Що на ньому відбувається:

- булевий тип, truthy/falsy-значення, оператори `and`/`or`/`not` і їх пріоритет, short-circuit-обчислення, `None`;
- `if`/`elif`/`else`, базовий `while`, `break`/`continue`;
- `if __name__ == "__main__"` тут навмисно **не** пояснюється — конструкцію показано без деталей ще на уроці 2, повне пояснення — на уроці 12 (модулі);
- задачі на рівні структури RETRIEVE → CONCEPT → PREDICT → RUN → INVESTIGATE → MODIFY → CREATE → TRANSFER, включно з transfer-задачею на нових поверхневих даних.
