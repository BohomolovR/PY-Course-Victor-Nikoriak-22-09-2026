# Урок 17. Узагальнення М1 + міні-проєкт CLI

Тип: Урок. Синтез усього модуля — пояснення зв'язків між темами, побудова міні-проєкту з CLI-інтерфейсом. Тут сходяться разом обидва потоки М1: «Я можу сформулювати задачу → визначити дані → спроєктувати перетворення → організувати код → зберегти стан → обробити помилки → оформити це як маленьку систему → вести її через Git.»

Джерело (аудит): `notes_module1_review.ipynb` (найбільший файл усього М1) — повний огляд уроків 3–14, 10 фундаментальних ідей курсу, checklist самоперевірки — готовий каркас. CLI mini-проєкт сам по собі відсутній: старий `calculator_project` визнаний недостатнім (не синтезує модуль достатньо широко). Новий базовий кандидат — **DATA / TASK TRACKER CLI** (`add`/`list`/`find`/`filter`/`stats`/`save`/`load`), що вимагає зібрати разом типи даних, колекції, умови, цикли, функції, алгоритмічне мислення, винятки, модулі, файли/JSON, CLI і Git. Проєктувати зверху вниз: яка задача? → які дані? → який стан? → які операції? → які перетворення? → як розділити систему? → лише тоді код.
