## Концепція модуля

> **Python Core: від задачі та інформації до першої програмної системи**

М1 будується не як послідовність ізольованих тем Python, а як поступове формування **computational thinking** через одну наскрізну модель мислення:

```text
задача → інформація → дані → перетворення → організація логіки → збереження та взаємодія → система
```

Це не один наскрізний проєкт на весь модуль — це одна модель, яку демонструють на різних задачах на різних етапах, аж до фінального CLI-проєкту на позиції 17.

```text
                       REAL-WORLD PROBLEM
                              │
                              ▼
01 ─────────────── MENTAL MODEL + WORKFLOW
02                         PROGRAM
03                          DATA
04                    DECISIONS / STATE
05–06              DATA STRUCTURES + FLOW
07                       FUNCTIONS
08                 ALGORITHMIC THINKING
09–10          ABSTRACTION + DATA STREAMS
11                        SEARCH
12                       MODULES
13                 FAILURE / RECOVERY
14                     PERSISTENCE
15              UNDERSTANDING GIT SYSTEM
16                  EFFICIENT LOOKUP
17                        SYSTEM
                     (CLI PROJECT)

     Git/GitHub ───────────────────────────────►
     HW → commit → push → PR → repeat → mastery
```

Git/GitHub — окремий **паралельний горизонтальний трек**, що йде поруч із Python з першого заняття (Pull Request — цільовий спосіб здачі домашніх робіт), а не тема, яку відкладають до кінця модуля. Практичні інструкції — у розділі [Як користуватися → GitHub](../../00_getting_started/github/README.md), тут вони не переказуються.

Кожен урок книги побудований за стандартизованим циклом **RETRIEVE → CONCEPT → PREDICT → RUN → INVESTIGATE → MODIFY → CREATE → TRANSFER** (докладно — `data/plan_md/migration_plan.md`, §1.2).
