# М2. Python Advanced

🚧 Контент у розробці. Наповнюється після завершення пілотної фази на М1.

Уроки модуля:

- [Урок 18. Функції як об'єкти першого класу](m2/lesson_18.md) — сервіс доставки після карантину: словник команд, `key=`, callback, фабрики й замикання, конвеєр з функцій.
- [Урок 19. Класи, простір імен](m2/lesson_19.md) — `DeliveryService` тримає стан і правила; атрибути класу й екземпляра, `@classmethod`; архітектура: функції, замикання чи клас. Практикум на реальних даних — «Титанік».
- [Урок 20. Наслідування, поліморфізм](m2/lesson_20.md) — таксі, кур'єр, самовивіз і нічний міксин з однаковим `fare()`; MRO, `super()`, качина типізація, LSP; архітектура: `if` за типом, ієрархія чи композиція. Практикум — «Титанік»: «Жінки та діти — першими».
