# SSH-ключі для GitHub

SSH-ключ дозволяє працювати з GitHub (клонувати, `push`, `pull`) без введення пароля щоразу. Потрібно згенерувати його один раз на кожному комп'ютері, з якого працюєш з GitHub.

## 1. Перевір, чи вже є ключ

У PowerShell:

```powershell
Get-ChildItem "$env:USERPROFILE\.ssh" -Filter *.pub
```

Якщо файл на кшталт `id_ed25519.pub` вже є — переходь одразу до кроку 4 (перевірка підключення). Якщо файлів немає — створи новий ключ.

## 2. Створи новий ключ

У PowerShell:

```powershell
ssh-keygen -t ed25519 -C "твій_email_на_GitHub"
```

Заміни `твій_email_на_GitHub` на свій email (той самий, що прив'язаний до акаунту GitHub).

- Коли запитає шлях збереження — натисни **Enter** (стандартний шлях).
- Далі введи пароль для ключа або натисни **Enter** двічі, щоб залишити без пароля.
- Якщо система запропонує **перезаписати наявний файл** — зупинись і не погоджуйся, спочатку з'ясуй, чи не потрібен той ключ, що вже є (наприклад, напиши викладачу).

## 3. Скопіюй публічний ключ

```powershell
Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub" | Set-Clipboard
```

Ключ скопійовано в буфер обміну.

## 4. Додай ключ на GitHub

Відкрий [додавання SSH-ключа на GitHub](https://github.com/settings/ssh/new) під акаунтом, якому належить репозиторій або надано доступ:

- **Title** — наприклад `Windows-PC` (щось, що допоможе впізнати цей комп'ютер).
- **Key type** — `Authentication Key`.
- **Key** — встав ключ через `Ctrl+V`.

Натисни **Add SSH key**.

## 5. Перевір підключення

```powershell
ssh -T git@github.com
```

Очікувана відповідь:

```text
Hi USERNAME! You've successfully authenticated, but GitHub does not provide shell access.
```

Це нормально — GitHub підтверджує, що ти автентифікований, доступу до shell не буде і не потрібно.

Після цього повтори свою Git-операцію (`git push`/`git pull`/`git clone`).

## Якщо PowerShell працює, а PyCharm — ні

Якщо перевірка `ssh -T git@github.com` у PowerShell успішна, а в PyCharm помилка залишається — це означає, що PyCharm використовує інший SSH-клієнт або інший шлях до ключів, ніж системний. Напиши викладачу з результатом команди

```powershell
Get-ChildItem "$env:USERPROFILE\.ssh" -Filter *.pub
```

щоб розібратись, який SSH використовує PyCharm.

⚠️ **Приватний ключ** (файл без розширення `.pub`, наприклад просто `id_ed25519`) нікому не надсилай — ні викладачу, ні в чат. Публічний ключ (`.pub`) — можна.
