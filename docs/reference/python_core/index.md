# Довідник: Python Core

Ці сторінки — повний довідник по темах М1, окремо від ноутбуків занять.

```text
📓 ноутбук заняття   → короткий контекст і задача "тут і зараз"
📖 цей довідник       → повна глибина теми: усі методи, усі нюанси, усі пастки
```

Читайте розділ, коли він потрібен саме зараз (під час домашньої роботи, перед співбесідою, коли забули синтаксис) — не обов'язково поспіль від початку до кінця. З відповідного уроку є посилання сюди саме в той момент, коли тема з'являється вперше в контексті задачі.
